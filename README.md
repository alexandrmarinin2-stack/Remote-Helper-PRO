# 🚀 Remote Helper PRO (PowerShell Edition)

**Мощный графический инструмент системного администратора для удаленного управления парком ПК в домене Active Directory.** 

Программа позволяет в пару кликов собирать информацию, устанавливать ПО, чистить временные файлы и перезагружать компьютеры без использования сторонних программ (TeamViewer, AnyDesk и т.д.).

---

## 🌟 Ключевые возможности (Features)

*   **🎨 Современный темный интерфейс (GUI)**: Написан на Windows Forms. Темный заголовок окна, цветовое разделение кнопок по зонам риска.
*   **🖥️ Мульти-режим**: Возможность подключаться к **нескольким ПК одновременно** (вводить через запятую: `PC-01, PC-02`). Команды будут выполнены на всех машинах параллельно.
*   **🌐 Умная проверка сети**: Перед подключением скрипт проверяет доступность ПК не только по пингу (ICMP), но и по портам **WinRM (5985)** и **SMB (445)**. Это спасает, если админы закрыли пинг.
*   **📦 Менеджер установки**: Встроенный выпадающий список файлов из папки `Installers`. Поддерживает установку `.msi` и `.exe` (с возможностью ввода ключей тихой установки).
*   **📝 Продвинутое логирование**: Все действия записываются в папку `C:\Logs\`. Если вы работаете с группой ПК, для **каждого ПК создается отдельный лог-файл** (например, `PC-01_2026-11-26.log`).
*   **🕘 История ввода**: Поле ввода имени ПК запоминает последние 10 введенных адресов (автодополнение).
*   **🔒 Безопасность (UAC)**: Скрипт сам запрашивает права администратора при запуске.

---

## 📁 Структура проекта (Почему разделено?)

Код специально разбит на модули. Это позволяет легко добавлять новые функции, не ломая существующие.

*   **`Start.ps1`** — Точка входа. Запрашивает права админа (UAC), подключает остальные модули и запускает интерфейс.
*   **`UI.ps1`** — Только визуальная часть. Здесь создаются окна, кнопки, поля ввода и прописывается логика нажатия на них.
*   **`Core.ps1`** — Сетевая логика. Проверка портов, создание и закрытие сессий WinRM.
*   **`Actions.ps1`** — «Мясо» программы. Здесь лежат функции, которые реально выполняются на удаленных компьютерах.
*   **`Utils.ps1`** — Вспомогательные функции (запись логов, сохранение истории).
*   **`Installers/`** — Папка для установщиков (создается автоматически).

## 🛠️ Как запустить и использовать

1.  Убедитесь, что на вашем ПК установлен **PowerShell** (встроен в Windows).
2.  Запустите файл **`Start.ps1`** (двойным кликом или правой кнопкой -> «Выполнить с помощью PowerShell»).
3.  Подтвердите запрос UAC (Запуск от имени администратора).
4.  Введите имя ПК (или несколько через запятую) и нажмите **Connect**.
5.  Дождитесь статуса `Connected` и пользуйтесь кнопками.

### 📦 Работа с установщиками:
1. Нажмите кнопку **Open Folder** рядом с выпадающим списком.
2. Закиньте туда любые файлы `.exe` или `.msi`.
3. Нажмите на кнопку **🔄** (Refresh), чтобы обновить список.
4. Выберите программу, нажмите **Install** и укажите ключи (например, `/S` для тихой установки).

## 🧑‍💻 Инструкция для разработчика (Как добавить свою кнопку)

Благодаря модульной структуре, добавить новую функцию проще простого. Допустим, вы хотите добавить кнопку «Очистить корзину».

**Шаг 1. Добавляем логику в `Actions.ps1`:**
```powershell
function Clear-RemoteRecycleBin {
    param($Session)
    return Invoke-Command -Session $Session -ScriptBlock {
        Clear-RecycleBin -Force -ErrorAction SilentlyContinue
        "Recycle Bin cleared."
    }
}
