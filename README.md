# 🚀 Remote Helper PRO (PowerShell Edition)

**Мощный графический инструмент системного администратора для удаленного управления парком ПК в домене Active Directory.** 

Программа позволяет в пару кликов собирать информацию, устанавливать ПО, чистить временные файлы и перезагружать компьютеры без использования сторонних программ (TeamViewer, AnyDesk и т.д.).

---

## 🌟 Ключевые возможности (Features)

*   **🎨 Современный темный интерфейс (GUI)**: Написан на Windows Forms. Полностью на русском языке. Темный заголовок окна, цветовое разделение кнопок по зонам риска.
*   **🖥️ Мульти-режим**: Возможность подключаться к **нескольким ПК одновременно** (вводить через запятую: `PC-01, PC-02`). Команды будут выполнены на всех машинах параллельно.
*   **🌐 Умная проверка сети**: Скрипт проверяет доступность ПК не только по пингу (ICMP), но и по портам **WinRM (5985)** и **SMB (445)**. Это спасает, если админы закрыли пинг.
*   **📦 Менеджер установки**: Встроенный выпадающий список файлов из папки `Installers`. Поддерживает установку `.msi` и `.exe` (с возможностью ввода ключей тихой установки).
*   **🔄 Обновления Windows**: Поиск и установка обновлений через встроенный COM-объект Windows Update.
*   **⚙️ Процессы**: Окно с топ-20 процессами, потребляющими больше всего ОЗУ, с возможностью принудительно завершить любой из них.
*   **📋 Журналы событий**: Вывод последних 30 критических ошибок из системного журнала за последние 24 часа.
*   **🔍 Массовый поиск**: Позволяет найти нужную папку (например, установленную игру или программу) на всех подключенных ПК. Результаты подсвечиваются зеленым (найдено) и красным (не найдено).
*   **📝 Продвинутое логирование**: Все действия записываются в папку `C:\Logs\`. Для каждого ПК создается отдельный лог-файл (например, `PC-01_2026-11-26.log`).
*   **🕘 История ввода**: Поле ввода имени ПК запоминает последние 10 введенных адресов.
*   **🔒 Безопасность (UAC)**: Скрипт сам запрашивает права администратора при запуске, а синее окно консоли автоматически скрывается.

## 📁 Структура проекта

*   **`Start.ps1`** — Точка входа. Запрашивает права админа (UAC), подключает остальные модули и запускает интерфейс.
*   **`UI.ps1`** — Визуальная часть. Окна, кнопки, поля ввода и логика нажатия.
*   **`Core.ps1`** — Сетевая логика. Проверка портов, создание и закрытие сессий WinRM.
*   **`Actions.ps1`** — «Мясо» программы. Функции, выполняемые на удаленных компьютерах.
*   **`Utils.ps1`** — Вспомогательные функции (запись логов, сохранение истории).
*   **`Installers/`** — Папка для установщиков (создается автоматически).
*   **`.gitignore`** — Защита от загрузки тяжелых файлов на GitHub.

## 🛠️ Как запустить и использовать

1.  Убедитесь, что на вашем ПК установлен **PowerShell** и **Git** (если планируете обновлять код).
2.  Запустите файл **`Start.ps1`** (двойным кликом или правой кнопкой -> «Выполнить с помощью PowerShell»).
3.  Подтвердите запрос UAC. Синее окно консоли исчезнет, откроется интерфейс.
4.  Введите имя ПК (или несколько через запятую) и нажмите **Подключить** (или клавишу Enter).
5.  Дождитесь статуса `Подключено` и пользуйтесь кнопками.

### 📦 Работа с установщиками:
1. Нажмите кнопку **Папка** рядом с выпадающим списком.
2. Закиньте туда любые файлы `.exe` или `.msi`.
3. Нажмите на кнопку **🔄**, чтобы обновить список.
4. Выберите программу, нажмите **Установить** и укажите ключи (например, `/S` для тихой установки).

## ⚠️ Важные требования (Troubleshooting)

Для успешной работы на удаленных ПК должны быть выполнены три условия:
1.  **WinRM должен быть включен**. В домене это обычно делается через GPO. Если ПК не в домене, его нужно включить вручную (`Enable-PSRemoting -Force`).
2.  **Права доступа**. Ваш аккаунт должен иметь права локального администратора на целевых машинах.
3.  **Кодировка файлов**. Если вы редактируете `.ps1` файлы, **всегда сохраняйте их в кодировке `UTF-8 с BOM`** (или ANSI). Иначе русский текст превратится в кракозябры, и скрипт упадет с ошибкой.
